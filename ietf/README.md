# Internet-Draft source

`draft-mailschema-mail-action-protocol-00.xml` is the individual-submission source for Mail Action Protocol. It deliberately describes MAP as an action vocabulary and authenticated HTTPS execution profile carried by the IETF Structured Email MIME model.

Build locally with the IETF `xml2rfc` author tool:

```sh
xml2rfc --text --html ietf/draft-mailschema-mail-action-protocol-00.xml
```

The draft requests no new media type, DNS record, well-known URI or other IANA registration. Implementation claims must remain aligned with the public conformance manifest and linked repository evidence.
