# MAP 0.1 conformance archive

MAP 0.1 is superseded by MAP 0.2. This directory preserves the published MAP 0.1 conformance manifest, requirements and cases. It is not part of the current conformance runner.

The manifest records the exact artifact and source hashes used by the original suite. Its fixtures remain available under `public/fixtures/map-0.1`. The retired MAP 0.1 runtime can be inspected or run from repository commit `ce53e2b`; it is not restored to the current code path.
